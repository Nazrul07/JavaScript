*** What are Response Headers?

- Remember that when the server responds, Fetch gives us a Response object:

fetch(url)
    .then(response => {
        console.log(response);
    });

That response contains information such as:

Response
├── status
├── ok
├── headers
├── body
└── ...


We've already used:

response.status
response.ok
response.json()


Now we're going to learn: response.headers




*** What are Headers?

- Headers are metadata about an HTTP request or response.
- Think of them as information attached to the HTTP message.

For example, the server might tell us:

Content-Type: application/json
Content-Length: ...
Cache-Control: ...

One particularly important header is: Content-Type -> It tells us what kind of content the server sent.

For example: Content-Type: application/json -> means the response body contains JSON.



*** Reading a Response Header

We can use: response.headers.get("Content-Type")

Example:

fetch("https://jsonplaceholder.typicode.com/users")
    .then(response => {

        const contentType =
            response.headers.get("Content-Type");

        console.log(contentType);

        return response.json();
    })
    .then(data => {
        console.log(data);
    });


The result might look something like: application/json; charset=utf-8 -> Exact value depends on the server.




*** Why Would We Need This?

Let, our application requests some data from a server.

We expect JSON: application/json

But server might return something else, such as: text/html

We can inspect the header before deciding how to process the response.

Now we can see what kind of content the server says it returned.
